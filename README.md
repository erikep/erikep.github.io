# Pomodoro Timer

This project is a simple [Pomodoro Timer](https://en.wikipedia.org/wiki/Pomodoro_Technique) that allows you to toggle between color settings and timer types. To enhance functionality, the program displays an overview of the current week's completed Pomodoro sessions.

ES6 modules require a remote or local server to allow module loading within browsers (blocked by CORS policy). With Python installed, run `python3 -m http.server 8000` to start local server then go to `http://localhost:8000` on your browser.
